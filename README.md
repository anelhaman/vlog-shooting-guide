# คู่มือถ่ายคลิปเตรียมทำ vlog ทริป

คู่มือนี้สำหรับทุกคนที่ไปทริปด้วยกัน ใช้ได้กับทุกที่ ทั้งทะเล ภูเขา เมือง หรือคาเฟ่

**เป้าหมาย:** คลิปแนวตั้ง ยาวประมาณ 60-90 วิ ถ่ายมาเยอะแค่ไหนก็ได้ เดี๋ยวค่อยตัดต่อทีหลัง

**หลักจำง่ายๆ:** คลิปที่คนพูดคือตัวเรื่อง ส่วนวิวคือภาพประกอบ พูดถึงอะไร ให้ถ่ายวิวของสิ่งนั้นเก็บไว้ด้วยทุกครั้ง

## ใครอ่านไฟล์ไหน

| คุณคือ | อ่านไฟล์ |
| --- | --- |
| คนถือกล้อง (ตั้งค่ากล้อง ถ่ายคนพูด ถ่ายวิว) | [camera.md](camera.md) |
| คนพูด (เล่าเรื่องใส่กล้อง) | [speaker.md](speaker.md) |
| ทำทั้งสองอย่าง (selfie) | อ่านทั้งสองไฟล์ |

อ่านแล้วทำการบ้านในหัวข้อ "ก่อนออกเดินทาง" ของไฟล์ตัวเองให้ครบก่อนวันไป
